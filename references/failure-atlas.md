# 生成故障图谱

## 使用顺序

1. 只描述画面证据，不先评价 Prompt。
2. 定位故障首次出现的时间、人物、身体部位、镜头相位和触发动作。
3. 判断属于身份、动作、注意力、摄影、参考冲突、连续性、声音或平台能力。
4. 保留成功层，只改一个主变量；记录本次假设和结果。

## 症状—根因—诊断—修复

| 症状 | 常见根因 | 如何诊断 | 首选修复 |
|---|---|---|---|
| 人脸漂移 | 重新描述参考图身份；大幅转头/遮挡；多人抢身份注意力 | 找首次漂移帧，检查是否发生转头、手遮脸、景别突变 | 用参考图锁身份；删掉重复外貌描述；减小头部角度；拆开大动作 |
| 五官在镜头中变化 | 超近景叠加复杂表情或运镜 | 固定帧对比眼距、鼻形、脸型 | 降低到中近景；固定机位；表情只留 1–2 个载体 |
| 眼神乱飘 | 没有视线对象；同时要求看多人/看镜头/看道具 | 标记每次目光跳转是否有触发 | 每段只写一个视线目标和一次转移，给出终点 |
| 双眼方向不一致 | 极端侧视、近距离大角度、头眼不同步 | 查看一只眼是否被遮或视线角度过大 | 用三分之二侧面；先转眼后转头；减少极端余光 |
| 眨眼机械 | 频率被过度规定；连续微表情堆叠 | 统计眨眼是否重复等间隔 | 只指定一次关键眨眼，其余交给自然表演 |
| 手指崩坏 | 精细手指动作、双手交互、手脸道具同时运动 | 找到手开始接触/交叉的帧 | 改为掌心、握拳、放下等简单姿势；接触拆成递出—确认—接过 |
| 道具穿手 | 道具所有者不清、两人同时拿、终点缺失 | 检查交接瞬间谁在持有 | 写明 A 保持、B 接稳、A 再松手；必要时切特写 |
| 手遮脸导致脸变 | 手部路径经过五官 | 查看漂移是否从遮挡开始 | 改用手背擦泪、触肩或胸前手势；不跨过脸中心 |
| 表情 AI 感 | 抽象形容词过强；笑、哭、怒同时堆叠；强度无过渡 | 检查是否从中性瞬间跳到 L4 | 用 L1–L4逐级变化；选眼、嘴、呼吸中的 2–3 项 |
| 嘴角与眼神不一致 | 需要假笑却未说明先后，或角色目标含混 | 分析笑是礼貌、真笑还是笑容冻结 | 明确“嘴角维持笑，眼神先停止微笑”，给触发点 |
| 哭戏过度 | 直接写崩溃大哭；同时有对白和大动作 | 检查泪、声音、身体是否一起爆发 | 先泪光/哽咽，主动作后再落泪；镜头固定 |
| 动作不执行 | 动词抽象；缺触发、路径或结果；任务过载 | 问“谁在何时做了什么、结果怎样”是否完整 | 写动作链与可观察终点；删次要动作 |
| 动作只做一半 | clip 时间不足或终点未写 | 末帧检查是否仍在抬手/转身 | 提前触发，缩短前奏；明确停点；续镜继承开放运动 |
| 动作重复 | 续拍未记录已完成节拍；Prompt 重述起点 | 对比上一镜尾帧和新镜开头 | 标记 completed beats；从当前尾帧继续，不再写“再次” |
| 人物滑行 | 走路路径和摄影机跟拍关系不清 | 看脚步是否与地面位移匹配 | 缩短走位；固定终点；侧跟同速，不叠加推近 |
| 转身变人 | 180°转身暴露身份脆弱；服装背面未锁 | 找到身份变化是否发生在背对阶段 | 限制到 45–90°；用侧面切镜；补服装背面锚点 |
| 多人抢戏 | 没有焦点人物；所有人同时有动作/表情 | 做逐秒角色表，看同一秒活跃人数 | 一动一静；背景人仅按顺序转眼；把反应拆到下一镜 |
| 多人身份互换 | 角色标签、左右关系或服装差异不足 | 检查名字是否被可见特征和位置绑定 | 用 A/B稳定标签；锁左右、衣色、发型、道具归属 |
| 对白说错人 | 未绑定说话者；两人都在动嘴 | 检查台词前是否明确角色和静止者 | `A说：“…”；B保持闭口只用眼神反应` |
| 口型不同步 | 台词长、头部/镜头移动、多人说话 | 检查失同步是否从转头或运镜开始 | 缩短台词；固定近景；单一说话者；必要时后期配音 |
| 声音相位重启 | 续拍未记录已完成对白/BGM段落 | 比较上一镜尾音和新镜开头 | 记录未完句、音乐小节、环境音；续镜从当前相位接入 |
| 运镜跳变 | 叠加推拉摇移；无起点终点；续拍重启镜头 | 绘制摄影机轨迹是否连续 | 保留一个主运镜；写软启动、速度、终点和停稳 |
| 变焦冒充推轨 | 只写“推近”，主体透视不变 | 看背景透视是否同步变化 | 写“摄影机物理缓慢靠近感、与主体距离缩短”，或接受固定镜头 |
| 环绕空间变形 | 角度过大、人物同时移动、背景复杂 | 找空间漂移发生角度 | 限制小角度 30–60°；人物静止；简化背景 |
| 手持过抖 | 只写“手持、紧张、混乱” | 看是否有突发大幅偏航 | 改成“细微呼吸式肩扛摆动，主体始终居中” |
| 焦点抽动 | 多次跟焦或前后景目标不清 | 统计焦点切换次数 | 只做一次焦点转移，终点锁定主角眼睛 |
| 连续性断裂 | 计划覆盖实际画面；未维护状态账本 | 核对上一验收尾帧和下一首帧 | 以观察状态为正史，更新服装、道具、位置、动作和声音 |
| 镜间跳帧/动作复位 | 两条Prompt独立生成；下一镜从计划姿势开始；遗漏上一镜未完成动作 | 逐帧比较上一镜最后稳定帧和下一镜第0秒的双手、视线、重心与道具 | 建立镜间接缝卡；用真实尾帧校正下一首帧；从相同或略后动作相位继续 |
| 换机位后场景不连 | 把尾帧直接当新机位首帧，或只锁人物未锁空间和光线 | 检查人物屏幕侧、背景锚点、主光方向和眼线 | 用真实尾帧作状态参考而非复制构图；明确允许改变的景别机位和必须继承的空间状态 |
| 左右关系翻转 | 跨轴、角色标签未绑定屏幕方向 | 对比相邻镜头 A/B 所在侧 | 锁 `A画面左、B画面右`；需要跨轴时用中性正面镜过渡 |
| 视线对不上 | 眼线高度、画外方向或人物位置冲突 | 画出双方视线线条 | 记录视线目标与高度；对切保持相反方向和近似角度 |
| 道具状态倒退 | 已打开/破损/喝完的状态未记录 | 查上一镜终点 | 写当前条件，不重复动作；道具状态与所有者进入锁定项 |
| 服装细节变化 | 每镜重述不同；遮挡后重绘；参考图职责混乱 | 对比颜色、领口、配饰、污渍 | 建服装锚点，后续只写“保持”；新损伤只增不减 |
| 参考素材冲突 | 多个参考控制同一身份/动作/场景 | 给每个参考列角色、范围、排除项 | 一素材一主职责；冲突时确定优先级或分次生成 |
| 参考视频偷走身份 | 只说“参考视频”，未限制迁移层 | 输出人物像参考视频演员 | 写“仅迁移动作/运镜节奏，不迁移人物、服装、场景” |
| 图生视频静止 | Prompt 重复静态外观，没有动作触发与结果 | 删除外貌词后看是否剩完整动词 | 保持参考外观，只补一个动作链和环境响应 |
| 产品/文字变形 | 运动中重绘标签；手遮挡；旋转过大 | 找标签首次不可读帧 | 产品静止、正面、手离开；文字后期叠加；旋转拆镜 |
| 背景人物畸变 | 群体数量多、每人都有动作 | 检查是否需要辨认每个背景人 | 降数量；设为低细节静止剪影或依次小反应 |
| VFX 噪点泛滥 | 无来源、路径、材质与消散；遮挡角色 | 将特效拆成来源—行为—结果 | 限一个效果；写来源、颜色/材质、路径、交互和消散终点 |
| 光线乱跳 | 多个光源变化、运镜导致曝光重算 | 看跳变是否与转向或特效同步 | 保留一个主光源方向；变化缓慢；不同时闪烁与运镜 |
| 画面“很电影”但剧情不清 | 空洞风格词挤占动作和关系 | 删除风格词后是否没有剧情动作 | 先写主动作、后果、构图与声音；风格只留可物理实现项 |
| 提示词被忽略 | 太长、层级冲突、否定词召唤不想要的对象 | 标注重复、冲突和同义堆叠 | 缩到核心合同；用正向保持项替代长串否定 |
| 生成被拦截 | 真实人物、版权、伤害或绕过式措辞风险 | 区分创作意图与受限具体表达 | 改为原创角色与安全制片语言；不尝试规避平台规则 |

## 保守返修模板

```text
保留上一版中已成功的[身份/场景/光线/声音]。本次只修复[一个变量]：镜头开始时[当前状态]，由[触发]引发[单一动作]，动作最终停在[可见终点]。摄影机[固定或单一运动]。保持[关键锁]不变。
```

## 尝试预算

- 第 1 次：只改最可能根因。
- 第 2 次：若同症状复现，降低强度、人物数或运镜之一。
- 第 3 次：拆镜或换更稳的输入模式/参考职责。
- 三次后仍失败：保留可用片段，考虑后期修复或重新设计，不继续盲目加词。
