# 镜间接缝系统

用于处理相邻分镜之间的剧情与画面连接，尤其是上一镜最后一帧和下一镜第一帧。连续性系统负责“状态记忆”，本系统负责“如何切过去”。

## 不可省略的规则

- N个clip必须有N−1个镜间接缝；每个相邻镜头都要做接缝判断。
- 分镜阶段先写“计划接缝”；上一镜生成并验收后，再用“真实接缝”覆盖计划。
- `真实稳定尾帧 > 计划尾帧`。下一镜不能继续依据已经落空的计划状态。
- 同一机位续拍继承画面、动作和摄影机相位；切到新机位继承剧情状态，不要求两帧像素相同。
- 上一镜已完成的动作、台词和运镜不得在下一镜重新开始。
- 最后一帧若变形、模糊或处在转场中，不用它续拍；选择最后0.5–1秒内更早的稳定帧，并相应修剪上一镜尾部。

## 先选择接缝类型

| 接缝类型 | 什么时候用 | 尾帧—首帧关系 | 生成方式 |
|---|---|---|---|
| 原位续拍 | 同一景别、同一机位、动作或运镜未完成 | 首帧直接继承真实尾帧和未完成运动 | 优先使用原生续拍或已验收视频作为来源 |
| 停稳后切镜 | 上一镜动作和摄影机已收住，下一镜换景别 | 状态相同，构图可变 | 用真实尾帧作状态参考，另做下一镜首帧 |
| 动作匹配切 | 一个动作跨两个角度完成 | 下一镜从相同动作相位或稍后相位继续 | 尾帧作姿态参考，禁止动作复位 |
| 视线匹配切 | 人物看向对象，下一镜揭示被看对象 | 眼线方向、高度和距离逻辑匹配 | 下一首帧按反向眼线构图 |
| 正反打 | 双人轮流说话或反应 | 维持180度轴线和相反眼线 | 分别生成首帧，角色屏幕侧固定 |
| 道具匹配切 | 证物、产品、酒杯等从人物镜切特写 | 道具位置、朝向、开合和持有者一致 | 以尾帧道具裁切或产品参考生成特写 |
| 遮挡切/擦镜 | 人物或物体经过镜头形成自然遮挡 | 遮挡方向和速度连续 | 两镜都保留同方向遮挡相位 |
| 声音先行/延续 | 视觉换镜但情绪不应断 | 环境声、台词尾音或音乐跨越切点 | 画面独立生成，剪辑时做声音桥 |
| 插入镜头 | 用产品、手、门、证物掩盖空间跳变 | 主场景状态在插镜期间冻结或合理推进 | 插镜独立生成，返回时更新经过时间 |
| 新场景转场 | 时间或地点明确改变 | 不继承机位，但继承人物、服装历史和道具历史 | 用新场景建立镜重新锚定空间 |

不要默认用“完全相同的尾帧和首帧”。新机位若复制同一画面，只会产生停顿或跳切；自然剪辑依赖状态、方向、动作相位和声音的匹配。

## 九项接缝检查

相邻镜头至少检查：

1. **人物**：身份、发型、年龄感和服装是否一致。
2. **空间**：人物在场景中的真实位置、前后关系和距离是否合理。
3. **屏幕方向**：谁在画面左/右，行走方向是否突然反转，是否越过180度轴线。
4. **姿态动作**：头、躯干、双手、腿和重心处在动作的哪个相位。
5. **视线**：看谁、看哪里、眼线高度是否匹配反打。
6. **道具**：由谁持有、哪只手、朝向、开合、剩余量和落点。
7. **摄影机**：上一镜在运动还是已停，新镜是延续运动还是明确切镜。
8. **光线环境**：主光方向、色温、天气、烟雾、帷幔等环境动态是否连续。
9. **声音**：对白是否说完，环境声、音乐、音效余响和静默如何跨越切点。

## 分镜阶段：计划接缝

在生成任何视频前，为相邻镜头填写：

```text
镜间接缝卡｜C[n] → C[n+1]
转场类型：
上一镜计划尾帧：
下一镜计划首帧：
必须继承：
允许改变：
跨镜动作：
声音桥：
已经完成、不得重演：
禁止跳变：
下一镜首帧来源：续拍 / 真实尾帧参考重构 / 独立建立镜
```

计划首帧必须能回答：下一镜第0秒人物的双手在哪里、看哪里、道具在哪里、摄影机在哪里。只写“承接上一镜”不合格。

## 生成阶段：真实接缝

上一镜生成后按以下顺序执行：

1. 只从已验收take中选择来源。
2. 查看最后0.5–1秒，而不是只看缩略图。
3. 选择最后一张身份、手、道具和构图都稳定的帧作为真实尾帧。
4. 记录它与计划尾帧的差异：人物位置、手势、视线、道具、摄影机、光线、声音。
5. 更新连续性账本。
6. 按真实尾帧重写下一镜的首帧生图Prompt和视频Prompt头部。
7. 若真实尾帧无法修复且不能自然衔接，拒绝该take或提前截断；不要让错误状态进入后续镜头。

不要批量独立生成所有镜头后再试图补连续性。可以先完成全部计划接缝，但正式生成应按场景顺序验收并回写。

## 下一镜首帧的三种制作方法

### A. 直接继承

用于同机位续拍。以上一条已验收视频或稳定尾帧作为来源，Prompt先延续未完成运动，再引入新动作。

```text
从上一条已验收视频的实际尾帧继续。A仍在画面右侧，右手正缓慢放下；摄影机仍以同一速度向前移动。先完成放手和摄影机停稳，再开始本镜新动作。不得重复上一句台词。
```

### B. 状态参考重构

用于切到新机位。真实尾帧只负责人物身份、空间状态、姿态、视线、道具和光线；下一首帧按新景别重新构图。

```text
参考上一镜真实尾帧中的人物身份、服装、站位、右手姿势、视线、道具和宫灯方向，但不要复制原来的大全景构图。切成平视双人中近景，A仍在画面右侧，B仍在画面左侧；A的右掌仍停在胸口，B保持双手交叠。
```

### C. 独立建立镜

用于明确换地点或换时间。重新建立场景空间，但继续继承人物身份、服装累积变化、随身道具和剧情事实。用环境音、动作结果或视觉母题建立联系。

## 跨镜动作规则

- 动作未开始：下一镜可以开始，但上一镜尾帧不得提前出现结果。
- 动作进行中：下一镜从相同或略后相位继续，不能回到起始姿势。
- 动作已完成：下一镜只保持结果或开始新动作，不能重演。
- 递接道具：尾帧和首帧必须明确谁在持有；不要把所有权变化藏在切点里，除非有插镜说明。
- 行走切镜：保持运动方向和步态相位；必要时在切点附近保留同一只脚的着地逻辑。
- 表情切镜：下一镜可提高景别展示反应，但情绪强度不能无触发地从L1跳到L4。

最稳的动作匹配不是逐像素相同，而是观众能理解“动作继续向前”。

## 摄影机接缝规则

- 上一镜推近已停稳：下一镜不能再次从同一位置重启同样推近，除非剧情有新触发。
- 上一镜仍在移动、下一镜续拍：继承方向、速度和主体距离，再设计软停止。
- 切换景别：变化应有叙事理由，例如从大全景切近景承接认知或反应。
- 正反打：锁定轴线、屏幕侧和眼线高度；过轴需使用中性正面镜、跟随过轴或空间建立镜。
- 相邻两镜构图几乎相同但人物位置略变时容易跳切；改大景别差、改变角度超过约30度，或使用动作/插镜掩盖。

“约30度”是剪辑经验，不是模型参数；若剧情有更合适的明确转场，可不机械遵守。

## 声音桥

自然衔接不仅靠画面。为每个接缝决定：

- 环境底噪是否连续；同一场景通常保持不中断。
- 下一句台词是否提前在上一镜尾部响起，形成声音先行。
- 上一句尾音、门响、杯响或音乐持续音是否跨过切点。
- 新场景是否先听到声音再看到画面，帮助观众接受地点变化。
- 已说完的台词不得在下一条生成视频中重复。

如果视频模型的原生声音不稳定，视觉Prompt仍记录声音逻辑，但在剪辑阶段完成声音桥。

## 接缝风险评分

每项不连续风险加1分：人物身份、左右/轴线、手势动作、视线、道具、摄影机相位、光线环境、声音相位。再按转场方式加分：

- 原位续拍且存在未完成复杂动作：+2。
- 多人或精细道具交接跨切点：+2。
- 新机位但缺少真实尾帧参考：+1。
- 最后一帧模糊、遮挡或畸变：+2。

风险等级：

- 0–2：低风险，可按计划生成。
- 3–4：中风险，必须制作首帧并做接缝验收。
- 5–6：高风险，改用稳定尾帧参考、动作匹配切或插镜。
- 7以上：不要直接续接；重做尾部、拆镜或建立新场景锚点。

## 接缝验收

把两条已验收视频首尾相接观看至少三次：

1. 静音看画面：检查人物跳位、手势复位、眼线错误、道具瞬移和光线跳变。
2. 只听声音：检查环境声断裂、台词重复、音乐重新起拍和音效余响中断。
3. 正常观看：判断注意力是否自然从上一镜焦点转到下一镜焦点。

接缝不通过时先确认错误属于尾帧、首帧还是剪辑点。优先选择稳定尾帧或调整切点；不要立刻重写整条视频Prompt。

## 面向用户的交付格式

普通创作者默认看到简表，不展示内部账本字段：

| 项目 | 内容 |
|---|---|
| 怎么切 | 动作匹配切 / 正反打 / 续拍等 |
| 上一镜怎么结束 | 可观察尾帧 |
| 下一镜怎么开始 | 第0秒首帧状态 |
| 必须保持 | 人物、左右、手势、视线、道具、光线、声音 |
| 可以改变 | 景别、机位、构图范围等 |
| 接过去的动作 | 哪个动作继续、完成或停止 |
| 不能出现 | 动作复位、人物换边、道具瞬移、台词重复等 |

在尚未生成上一镜时标注“计划接缝”；生成后改成“按已验收真实尾帧更新”。
