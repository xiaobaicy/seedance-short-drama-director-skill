# 中文微短剧配方

配方是叙事骨架，不是固定台词。每个 clip 只完成一个剧情任务；先拍可验证的反应，再推进下一动作。默认竖屏时把脸、手中关键物和字幕安全区纳入构图。

## 宫斗：表面礼数，暗中交锋

**节拍**：礼貌建立 → 物件/称谓露出破绽 → 主角克制反应 → 一句双关 → 对手笑容冻结。  
**三镜模板**：①双人中景锁定尊卑与左右；②证物特写或过肩近景；③主角轻低机位近景，极缓推入。  
**表演**：主角 L1 观察、L2 单眉/冷笑；对手延迟半拍，手指收紧但身体不动。  
**连续锁**：发饰、袖口纹样、座次、茶杯归属、跪/站状态、称谓与环境音。  
**Prompt 模板**：`宫殿内双人中近景，A站在画面右侧先看一眼B手中的茶杯，再抬眼含笑说完双关；B保持坐姿，笑容在句尾冻结，手指慢慢收紧杯沿。摄影机从平视极缓推向A，终点停在A的冷静目光。`

## 霸总/豪门：权力差与边界变化

**节拍**：权力构图 → 对方提出条件 → 主角用极小动作夺回控制 → 关系距离改变。  
**三镜模板**：①低机位中景让主角入场；②过肩对话；③道具落桌/挡门的动作终点。  
**表演**：权力方呼吸平稳、动作慢；弱势方先肩内收，反转时站直并稳定直视。  
**禁忌**：无因果壁咚、摔文件、扯手腕同时发生。  
**Prompt 模板**：`他从画面左侧走到桌前只停一步，把合同平稳放到桌面中央，手指完全松开后抬眼。低机位中景缓慢推近；她始终坐着不动，只在最后一句后挺直背部。`

## 逆袭/打脸：证据先于庆祝

**节拍**：对手占优 → 关键证据出现 → 群体注意力转移 → 对手失语 → 主角克制收尾。  
**四镜模板**：①对手中景；②证据特写；③对手反应近景；④主角中景离场。  
**表演**：主角不提前得意；背景人物按左右顺序转眼，不同步大动。  
**声音**：证据落桌声、短暂静默、最后一句清楚收尾。  
**Prompt 模板**：`A把证据推到桌面中央后收回手，先保持沉默；B低头确认，笑容逐渐消失。背景三人依次把视线转向B，身体不动。固定中景，最后A眼尾轻弯并转身离开。`

## 重生/觉醒：认知变化必须可见

**节拍**：环境锚点 → 身体/记忆异常 → 看见关键物 → 认知聚焦 → 第一个新决定。  
**三镜模板**：①固定近景从失焦到聚焦；②关键物特写；③中景起身完成第一步行动。  
**表演**：不靠旁白喊“我重生了”；用日期、伤痕、戒指、镜中服装作为证据。  
**Prompt 模板**：`她睁眼后目光先散在天花板，听见钟声才缓慢聚到床边日历；短促吸气，手停在旧伤处。镜头从近景缓慢拉到中近景，她坐起并看向门口，动作收住。`

## 悬疑/审讯：信息控制与反应证据

**节拍**：规则空间 → 一个异常细节 → 提问 → 被问者露出微破绽 → 提问者确认。  
**镜头**：对称双人中景、证物插镜、被问者正面近景；摄影机尽量稳定。  
**表演**：破绽只选一项：眨眼遮掩、视线断裂、吞咽或手部收紧。  
**Prompt 模板**：`审讯室固定近景，问题落下后他保持笑容，呼吸却停了一拍，随后重重眨眼并看向桌角；提问者全程静止，只用余光确认这次破绽。`

## 仙侠：力量结果比形容词重要

**节拍**：力量来源 → 运动路径 → 与人物/环境交互 → 可见后果 → 粒子消散与角色终点。  
**拆镜**：人物起势、能量作用、对手后果分开；复杂战斗不用一个短镜完成。  
**表演**：施法者动作简洁；衣袖、发丝、尘土只作环境响应。  
**Prompt 模板**：`全景，她右手从腰侧抬到胸前后停住，掌心蓝白光点聚合成一束沿直线击向石门；石门表面先出现裂纹再向内崩落，尘粒缓慢散去。摄影机固定，人物站姿和面容保持不变。`

## 古装权谋：安静空间里的立场转换

**节拍**：座次建立 → 密信交接 → 一方不接 → 权力反转 → 新命令。  
**表演**：递信者先伸手并静止，接收者确认后决定接或拒；两人不要同时抢道具。  
**Prompt 模板**：`A双手递出密信并停在两人之间，B先看信封封蜡，再抬眼看A，双手始终不动；沉默两秒后B侧身让出门口。固定双人中景。`

## 甜宠/暧昧：距离与延迟

**节拍**：共同任务 → 意外靠近 → 视线停留 → 一方微退 → 未完成接触。  
**镜头**：双人中近景或侧面近景，极缓推；动作和相机都小。  
**表演**：一人先动，一人延迟；不在同镜完成靠近、牵手、拥抱、亲吻。
**Prompt 模板**：`两人同时伸手拿桌上照片，A的指尖先碰到照片边缘，B的手在几厘米外停住；两人隔半拍抬眼对视，B嘴角轻扬后垂眼，摄影机极缓推近。`

## 家庭伦理：关系伤害落在具体生活动作上

**节拍**：日常动作 → 一句伤人话 → 动作中止 → 延迟反应 → 生活物件成为情绪终点。  
**镜头**：厨房/餐桌中景，保留手和物；高潮用近景，不乱切。  
**Prompt 模板**：`母亲正在盛汤，听到那句话后勺子停在碗上方，汤面轻晃；她没有回头，长呼气后把勺子放回锅边，最后才转眼看向门口。`

## 职场逆袭：专业动作取代口号

**节拍**：被质疑 → 数据/作品出现 → 清楚陈述 → 决策者反应 → 身份位置改变。  
**镜头**：会议室关系全景、屏幕/文件特写、主角中近景。  
**连续锁**：投影内容、座次、电脑朝向、文件页码、发言顺序。  
**Prompt 模板**：`她把报告翻到标记页并推向主管，手离开后才开口，语速均匀，最后一个字清楚收住；质疑者保持坐姿，只在数据出现时停止转笔。`

## 校园青春：不说破的反应

**节拍**：共同空间 → 视线发现 → 小物件交接 → 同伴打断 → 留下未说出口的话。  
**镜头**：自然平视、中长焦感、环境光；群演只做低强度背景循环。  
**Prompt 模板**：`走廊中景，A把借来的笔放到B课本上，手指松开后仍停半拍；B抬眼正要开口，远处同学叫名字，两人同时只转眼，不转身。`

## 都市复合/离别：动作终点比台词更重

**节拍**：试图挽留 → 接触前停住 → 对方决定 → 物件归还 → 屏幕方向离开。  
**镜头**：侧面双人中景、手部插镜、缓慢拉远。  
**Prompt 模板**：`他抬手想抓住她的手腕，却在触碰前停住；她低头看那只手，把钥匙放入他掌心后先松手，随后向画面右侧离开，镜头缓慢拉远。`

## 带货剧情：冲突—证据—使用—结果

**节拍**：生活痛点 → 产品作为解决动作 → 一个可验证细节 → 使用后的生活结果 → 简短利益点。  
**分镜**：①痛点中景；②产品外观静态英雄镜；③单一步骤使用；④结果反应；⑤包装/名称稳定收尾。  
**产品锁**：外形、标签、颜色、开合结构、左右朝向全程不变；不要让文字在运动中重绘。  
**Prompt 模板**：`@图片1仅绑定产品外观和标签。她把产品正面朝镜头放在桌上，手完全离开后再按一次顶部按钮；指示灯由灭转亮，房间噪声随即降低，她的肩膀放松。固定中近景，产品文字和结构保持不变。`

## 直播间剧情：人、产品、字幕分层

**节拍**：主播抛问题 → 助播递产品 → 主播演示一个动作 → 观众反馈用后期字幕表达 → 固定收口。  
**规则**：生成阶段不要求变化中的小字和弹幕；字幕、价格和销量优先后期叠加。  
**Prompt 模板**：`主播保持正面中近景，助播从画面左侧只把产品递到桌面中央，主播确认产品放稳后再拿起演示一次开合；摄影机固定，标签始终正对镜头，画面内不生成动态文字。`

## 广告剧情/品牌短片：单一证明点

**节拍**：需求 → 产品动作 → 材质/功能后果 → 人物反应 → 英雄定格。  
**镜头**：产品几何脆弱时让人物和相机减速；复杂流体、开合、旋转分镜完成。  
**Prompt 模板**：`@图片1绑定瓶身、颜色和标签。微距感固定镜头，透明液滴从滴管落到皮肤表面并缓慢铺开；切换为中近景，她只轻触一次脸颊并微笑。最后产品正面静止居中，文字不变。`

## 通用 5-clip 结构

1. `C01 建立`：人物、空间、关系和问题；中景，低复杂度。
2. `C02 触发`：一个信息或物件改变状态；近景/插镜。
3. `C03 反应`：核心人物从 L1 到 L2/L3；稳定近景。
4. `C04 决定`：一个可见主动作改变关系；中景。
5. `C05 结果`：对手反应或空间后果；静止/拉远，为续集留开放状态。

每个 clip 验收后更新连续性账本，再写下一条 Prompt；计划中的爽点、反转或道具不能提前泄露。
