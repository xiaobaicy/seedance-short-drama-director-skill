# 动作复杂度评分与自动拆镜

本评分用于比较方案风险，不是官方模型指标。先按 clip 计算基础分，再加冲突修正。自然眨眼、呼吸和衣摆微动不计分，除非它们是剧情关键动作。

## 基础分

### 人物与注意力

| 项目 | 分数 |
|---|---:|
| 1 名清晰人物 | 0 |
| 第 2 名清晰人物 | +1 |
| 第 3 名清晰人物 | +2 |
| 第 4 名及以后，每人 | +2 |
| 可辨认背景群体 | +2 |
| 同一秒内两个以上人物主动表演 | +2 |

### 主体动作

| 动作 | 分数 |
|---|---:|
| 单一小动作：抬眼、放下、点头 | 0 |
| 一般位移：起身、转身、走 1–2 步 | +1 |
| 大位移：跑、跌倒、跳跃、抱起 | +2 |
| 接触：握手、扶、拥抱、抢夺 | +2 |
| 打斗、舞蹈、多人编排 | +3 |
| 每增加一个独立主动作 | +1 |
| 动作无明确触发或终点 | +1 |

### 手、脸与身份脆弱项

| 项目 | 分数 |
|---|---:|
| 单手简单姿势 | 0 |
| 精细手指动作或双手交互 | +1 |
| 手接触脸/遮脸 | +1 |
| 两人交接小道具 | +2 |
| 大角度转头、遮挡后重现 | +1 |
| L3 面部爆发 | +1 |
| L4 哭喊/崩溃 | +2 |

### 对白与声音

| 项目 | 分数 |
|---|---:|
| 无对白或单人短句 | 0 |
| 单人长句 | +1 |
| 两人轮流说话 | +2 |
| 边走/转头/手部动作边说 | +2 |
| 多人同时说或抢话 | +3 |
| 精确口型 + 明显运镜 | +2 |
| 同时要求对白、音乐卡点和多个音效 | +2 |

### 摄影机与空间

| 项目 | 分数 |
|---|---:|
| 固定或单一缓慢运镜 | 0 |
| 单一快速运镜 | +1 |
| 两段不同运镜 | +1 |
| 三种及以上运镜 | +3 |
| 环绕超过小角度或主体同时移动 | +2 |
| 机位跨轴/穿越遮挡 | +2 |
| 未写起点、速度或终点 | +1 |

### 场景、道具、VFX 与参考

| 项目 | 分数 |
|---|---:|
| 单一稳定场景 | 0 |
| 场景转换/时间跳变 | +2 |
| 产品标签、小字或刚性结构需保持 | +1 |
| 简单天气/粒子环境响应 | +1 |
| 复杂破坏、流体、变身、爆炸 | +2～3 |
| 2 个参考素材职责清晰 | 0 |
| 3 个以上参考素材 | +1 |
| 两个参考控制同一层 | +2 |
| 续拍但没有验收尾帧状态 | +2 |

## 冲突修正

下列组合额外加分，因为会争夺同一注意力或几何稳定性：

- 近景面部 L3/L4 + 精细手部：+2。
- 对白口型 + 转头超过 45°：+2。
- 两人接触 + 摄影机环绕：+2。
- 产品/文字 + 手遮挡或旋转：+2。
- 多人主动动作 + 复杂 VFX：+2。
- 续拍开放运动 + 新的大动作：+2。
- 同时要求“保持完全不变”和“大幅改变同一对象”：+3。

## 风险等级

| 总分 | 级别 | 决策 |
|---:|---|---|
| 0–2 | A 稳定 | 可直接编译；仍写清终点 |
| 3–5 | B 可控 | 保留单一主动作，弱化配角 |
| 6–8 | C 高风险 | 默认拆镜或删除一个高分项 |
| 9–12 | D 过载 | 必须拆为至少 2–3 个 clip |
| 13+ | E 不可用 | 重新设计动作链和镜头结构 |

## 自动拆镜规则

任一条件成立就拆镜，不等待总分：

1. 一个短 clip 包含两个地点或明显时间跳变。
2. 三名以上角色需要各自清晰表演或说话。
3. 同一镜要求“接近 → 接触 → 冲突 → 分离 → 结果”。
4. 同时要求精确口型、精细手部和明显运镜。
5. 运镜有三个独立阶段且每阶段都承担新剧情信息。
6. 关键产品文字在旋转、遮挡或形变中仍需清晰。
7. 打斗/法术同时要求起势、命中、环境破坏和对手情绪反应。
8. 续拍需要先完成上一镜开放运动，又要引入新高潮。

## 拆镜算法

按因果边界拆，不按字数平均拆：

1. 列出 `初始状态 → 触发 → 主动作 → 直接结果 → 反应 → 新决定`。
2. 找到第一个可稳定停住的局部终点，作为 Clip A 尾帧。
3. Clip B 从这个真实终点开始，先拍反应或后果，再引入新动作。
4. 每个 clip 重新评分，目标降到 0–5；高潮镜最多 6–7，但摄影或配角必须简化。
5. 为每个尾帧写道具、视线、身体姿势、镜头和声音交接。

## 示例 1：两人争执

原方案：`A走近质问并推B，B摔倒后哭喊，摄影机环绕，第三人冲入阻止。`

- 2 人 +1；第三人 +2；走近 +1；推搡 +2；摔倒 +2；哭喊 +2；环绕与接触冲突 +4；第三人冲入 +1。总分至少 15，E 级。
- 拆法：
  - C01：A走近一步质问，B静止，只在句尾后退半步；固定双人中景。
  - C02：A抬掌制止/推开动作只做一个，B失衡扶桌，不摔倒；固定中景。
  - C03：B反应近景，第三人在画外喊停；下一镜再入场。

## 示例 2：带货演示

原方案：`主播边走边介绍，旋转瓶身、打开瓶盖、挤出液体、涂脸，镜头环绕，标签始终清晰。`

风险来自口型+走位、连续精细手部、产品旋转、涂脸和环绕，D/E 级。

- C01：产品静止英雄镜，标签清楚。
- C02：固定手部特写，只完成开盖和挤出一滴。
- C03：主播固定中近景，只做一次轻触脸颊并说短句。

## 输出格式

```text
复杂度：7 分（C 高风险）
主要风险：两人接触 + 环绕；精确口型 + 转头。
决定：拆为 2 镜。
C01：触发与接近，终点……（3 分）
C02：反应与决定，起点继承……（2 分）
```

不要用评分替代导演判断：若用户明确追求实验性长镜，可保留创意版，但同时交付一个低风险执行版并说明最脆弱的环节。
