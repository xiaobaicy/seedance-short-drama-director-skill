# 镜头语言库

## 镜头执行参数

每个短镜头写清：`景别 + 机位 + 焦段感 + 起始构图 + 单一主运镜 + 速度 + 与人物关系 + 终止构图`。这些项目必须编入最终视频 Prompt，不能只留在分镜说明中。焦段写“感觉”而非未经平台确认的硬参数。情绪表演和口型优先稳定机位；一镜到底也要分动作段，不等于堆叠所有运镜。

## 景别

| 景别 | 画面职责 | 适合情绪/剧情 | 常见失败与修正 |
|---|---|---|---|
| 大远景 | 建立世界、人物渺小 | 孤独、逃亡、仙侠尺度 | 人物身份弱；减少面部要求 |
| 远景 | 看清人物与环境关系 | 入场、对峙前布局 | 同时要求微表情；另切近景 |
| 全景 | 保留全身和动作路线 | 起身、挡路、走位 | 手脸细节不稳；动作只留一个 |
| 中景 | 腰部以上与关系距离 | 对话、递物、权力关系 | 背景抢戏；限制背景人物动作 |
| 中近景 | 胸部以上兼顾手脸 | 微短剧默认、克制表演 | 手脸同时复杂；让手势简单 |
| 近景 | 面部与少量肩部 | 认知转折、隐忍、怀疑 | 表情过度；降到 L1–L2 |
| 特写 | 单一细节 | 泪、戒指、证据、手指 | 细节变形；镜头固定、动作极简 |
| 大特写 | 眼睛或嘴部 | 极短心理强调 | AI感强；仅作 0.5–1.5 秒插镜 |

## 机位与构图

| 机位 | 感受 | 适用 | 风险 |
|---|---|---|---|
| 平视 | 平等、真实 | 常规对话、情感戏 | 容易平；靠走位和表演制造层次 |
| 轻低机位 | 权力、压迫 | 霸总、不怒自威、反派 | 过低易夸张和脸变形 |
| 轻高机位 | 脆弱、受困 | 委屈、失败、审讯 | 过高削弱身份一致性 |
| 正面 | 直接、审判 | 宣言、被看穿、情绪特写 | 对称过久僵硬 |
| 三分之二侧面 | 自然、保留轮廓 | 绝大多数表演近景 | 左右关系要锁定 |
| 过肩 | 对话与权力 | 审问、谈判、暧昧 | 肩部遮脸；明确肩只占画面边缘 |
| 侧面双人 | 距离与接触 | 对峙、靠近、递物 | 交叉轴线；保持屏幕方向 |
| 背面/越肩看 | 隐秘、未知 | 进入房间、发现秘密 | 主体身份弱；下一镜补正面锚点 |
| 荷兰角 | 失衡 | 短促危机点 | 易廉价；只用一次且幅度小 |
| 框中框 | 监视、困局 | 宫斗、悬疑 | 环境线条复杂；保持主体清晰 |

## 焦段感

| 焦段感 | 视觉关系 | 适用 | 常见失败 |
|---|---|---|---|
| 超广角感 | 空间夸张、边缘拉伸 | 逼仄空间、奔逃 | 脸和手变形，不用于近距离情绪戏 |
| 广角感 | 环境参与、距离被拉开 | 入场、多人布局 | 背景信息过载 |
| 标准焦段感 | 接近人眼、自然 | 真人对话默认 | 缺乏强调时用构图解决 |
| 中长焦感 | 背景压缩、主体突出 | 近景、权力对峙 | 走位空间显窄，别要求大横移 |
| 长焦感 | 远距离窥视、压缩强 | 悬疑监视、群体中找人 | 跟拍易漂；尽量锁定主体 |
| 微距感 | 材质和细节 | 戒指、药瓶、指尖 | 景深极浅；只允许轻微动作 |

## 运镜词典

| 运镜 | 强表达方式 | 适合 | 常见失败与修复 |
|---|---|---|---|
| 固定 | 固定中近景，人物在画面内完成表演 | 对白、微表情、口型 | 画面死；让光、呼吸或前后景有微动 |
| 推近 | 从中近景极缓推到近景，终点落在眼神 | 认知、压迫、秘密 | 变成数字变焦；写明摄影机物理靠近感与终点 |
| 拉远 | 从近景缓慢拉到中景，显露关系或孤立 | 失望、后果、空间揭示 | 主体缩得过快；限定速度和终点 |
| 横摇 | 从 A 的反应平稳摇到 B，B 已在空间中 | 信息接力 | 甩镜、找不到人；写明方向和终点构图 |
| 俯仰 | 从手中证物缓慢仰到人物脸 | 证据到反应 | 同时人物大动；让人物等待镜头到达 |
| 横移 | 摄影机平行小幅移动，保持主体三分之二侧面 | 走廊、关系变化 | 背景视差乱；路径短、速度匀 |
| 跟拍 | 与人物同速侧跟或后跟，距离恒定 | 入场、离开、追随 | 速度漂移；只跟一个主体，写停点 |
| 环绕 | 围绕静止双人小角度慢移，终点换权力构图 | 暧昧、对峙转折 | 人脸与空间漂；限制 30–60°，人物少动 |
| 升降 | 从低位缓升到胸口高度 | 身份揭示、站起 | 与人物起身冲突；只保留一个升降来源 |
| 手持 | 细微呼吸式肩扛摆动，主体保持居中 | 恐惧、现场感 | 变成剧烈抖动；明确“细微、无突然摆动” |
| 弧线滑轨 | 从侧前方滑到正面，结束在对称构图 | 权力揭示、产品 | 容易被解释成环绕；写起止角度 |
| 跟焦 | 焦点从前景证物转到后景人物 | 秘密、发现 | 焦点来回抽动；只转一次并锁住终点 |

## 速度词

- 极缓：适合 L1–L2 微表情、危险平静；全程几乎察觉不到加速。
- 缓慢均匀：适合推近、拉远、横移；起止都有软启动和软停止。
- 中速平稳：适合入场、侧跟；人物步速恒定。
- 短促快速：只用于触发瞬间的推近或摇摄，0.5–1 秒后必须停住。
- 突然中止：服务惊吓或认知断裂；不能与复杂演员动作同时发生。

避免“快速、丝滑、动感、史诗、电影感”这类没有轨迹与终点的词。

## 起点—终点模板

```text
从[起始景别/角度/主体位置]开始，摄影机以[速度]做[单一运动]，在[动作触发]期间始终[与主体的关系]，最后停在[终止景别/角度/构图焦点]，停稳后保留[0.5–1 秒]。
```

示例：`从门框外的中景开始，摄影机与她同速向右侧跟，始终保持三分之二侧面；她在桌边停步时摄影机同步软停止，终点为她与坐着的对手同框的双人中近景。`

## 情绪到镜头的优先映射

| 情绪 | 首选 | 备选 | 不宜 |
|---|---|---|---|
| 隐忍、心虚 | 固定近景 | 极缓推近 | 环绕、剧烈手持 |
| 不怒自威、决绝 | 轻低机位中近景 | 缓推 | 超广角脸部近拍 |
| 绝望、失望 | 缓拉远 | 固定中景 | 快推快拉 |
| 恐惧、警觉 | 轻微手持或短摇 | 固定留白 | 无方向甩镜 |
| 暧昧 | 双人近景极缓推 | 小角度环绕 | 多次切换焦点 |
| 悬疑发现 | 证物到脸一次仰拍/跟焦 | 过肩推近 | 同时摇移推 |
| 爽点反转 | 反应近景后主角中景 | 短促推近 | 群体同时运动 |

## 一镜到底规则

一镜到底只允许一条连续摄影轨迹，并把人物动作按段落交给镜头：建立空间 → 跟随一个主体 → 在转折点停住。若需要转场、换地点、多人交替主导或三种以上镜头运动，拆成多个 clip；不要用“一镜到底”掩盖过载。
