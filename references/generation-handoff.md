# AI生图与生视频交付

用于把导演分镜转换成普通创作者可以实际操作的生成任务。不要假设用户已经知道 `@图片1` 对应什么，也不要在用户尚未上传素材时编造引用编号。

## 每镜必须交付的 AI生成操作卡

当用户需要落地生产时，每个Clip按下面顺序输出：

1. **这镜要准备什么**：列出已有或待生成的角色、场景、产品、首帧和声音素材。
2. **推荐生成方式**：文生视频、单图图生视频、多参考视频、首尾帧或续拍；说明为什么。
3. **先生成哪张图**：给出可复制的首帧生图Prompt。首帧表现动作开始前的状态，不能提前画出动作终点。
4. **可选尾帧图**：只有终止构图很重要且当前入口支持首尾帧时才提供；尾帧应是动作完全收住的状态。
5. **怎么上传**：用自然名称说明每份素材的职责；等用户上传后再根据界面实际顺序写 `@图片1` 等标签。
6. **视频Prompt**：只描述首帧之后发生的变化，不重复重画静态人物和场景；但必须完整编入动作时间轴和镜头执行参数，包括景别、机位、焦段感、起点、运镜、速度、主体关系与终点。
7. **声音处理**：说明使用原生对白、后期配音或画外音；不要假设当前入口必然支持某种音频模式。
8. **验收标准**：列出3–6个一眼能检查的通过条件。
9. **失败时先改什么**：只给一个最优先的保守修复变量。

## 生成方式选择

| 条件 | 首选 | 原因 |
|---|---|---|
| 没有固定人物，单纯建立环境 | 文生视频或先生成场景首帧再图生视频 | 准备成本低 |
| 角色脸、服装、站位必须稳定 | 首帧图生视频 | 首帧直接锁定身份与构图 |
| 多人、产品、复杂空间同时出现 | 先用生图工具合成完整首帧，再以该图图生视频 | 避免多个参考互相争夺控制权 |
| 动作终点构图必须精确 | 首尾帧模式（仅在当前入口支持时） | 同时约束开始与结束 |
| 从上一条已验收视频继续 | 原生续拍或以上一条视频/尾帧作为来源 | 继承真实结束状态 |
| 只参考某段运镜或动作节奏 | 多参考/视频参考 | 明确仅迁移运动层，不迁移身份 |

若不清楚当前入口支持什么，默认使用“完整首帧图 + 图生视频”，这是最容易理解和复现的交付方式。

## 首帧生图规则

- 首帧是第0秒，而不是分镜海报或动作高潮。
- 角色数量、左右位置、视线目标、双手位置、产品状态和摄影机景别必须与视频起点一致。
- 不在首帧里画运动模糊、连续动作、多个时间状态或人物刚完成的动作。
- 多人场景让背景人物保持中性静止，焦点人物面部和手部清楚。
- 产品在首帧不是焦点时可以只保持轮廓与颜色；产品英雄镜才要求正面标签完整。
- 生图工具不擅长准确小字时，使用产品原图合成或后期替换标签，不反复抽卡重绘文字。

## 实际操作模板

多镜项目不要把全部clip彼此独立地一次生成。先完成全片的计划接缝，再按场景顺序执行“生成上一镜 → 验收 → 提取真实稳定尾帧 → 更新接缝卡 → 校正下一镜首帧与视频Prompt → 生成下一镜”。详细规则见 [镜间接缝系统](shot-seam-system.md)。

### A. 没有任何参考图

1. 先生成角色定妆图：正面、三分之二侧面、全身各一张，服装和光线中性。
2. 生成场景空镜图，锁定空间布局和主光方向。
3. 用角色与场景参考生成该Clip的完整首帧图。
4. 检查首帧中的脸、人数、左右位置、双手与道具；首帧不通过，不进入视频生成。
5. 把通过的首帧上传到Seedance，选择图生视频/首帧模式，设置目标时长与画幅，再粘贴视频Prompt。

### B. 已有角色、产品和场景图

1. 给素材起自然名称：皇帝参考图、太监参考图、产品正面图、大殿空景。
2. 先生成或合成完整首帧，不直接把所有素材无说明地塞进视频模型。
3. 如果当前入口允许额外参考，再上传关键身份或产品图，并逐一限定职责。
4. 按实际上传顺序把自然名称替换成准确的 `@图片N` 标签。

## C01 示例：皇帝抬手让众人退下

### 这镜要准备什么

- 皇帝定妆参考图：锁脸、年龄感、发型、黑金龙纹常服。
- 太监定妆参考图：锁脸、帽饰和暗红宫服。
- 大殿空景参考图：锁对称中轴、宫灯和队列空间。
- 完整首帧图：皇帝、太监、秀女和大殿已经组合在同一画面。
- 台词音频可选：`都退下吧。`

秀女不需要逐人身份参考，只作为两列低细节静止背景。

### 推荐生成方式

首选“完整首帧图 + 3秒图生视频”。原因：画面同时有皇帝、太监、两列秀女和对称大殿，纯文生视频容易改变人数、站位和皇帝身份。若当前入口支持首尾帧，可补一张抬掌后的尾帧；否则只用首帧。

### 首帧生图Prompt

```text
9:16竖屏，写实中国古装宫廷短剧画面，庄严金碧辉煌的大殿，对称中轴构图，从殿门方向看向殿内，轻微低机位、大全景、标准偏广角感。皇帝站在画面中央中轴，穿黑金龙纹常服，肩背展开，下巴水平，双手自然垂在身体两侧，尚未抬手，面部平静严肃；太监穿暗红宫服、戴黑色帽饰，站在皇帝左后方，双手交叠；两列秀女整齐分列大殿左右，全部垂眼静止，服装雅致但不抢主体。宫灯暖光从上方和两侧照明，皇帝清晰，背景人物适度简化，画面无文字、无水印、无运动模糊。
```

注意：首帧中皇帝的手必须仍在身体两侧，因为抬手是视频中的主动作。

### 可选尾帧生图Prompt

```text
保持首帧中所有人物身份、服装、人数、队列、灯光、景别和中轴构图完全一致。皇帝仍站在中央，右手掌心朝外抬到胸口高度并稳定悬停，视线停在右侧秀女方向，嘴唇刚说完一句短命令；太监和两列秀女仍保持静止，没有人退场。摄影机比首帧轻微靠近，但仍是大全景，无文字、无水印、无运动模糊。
```

### 怎么上传

最稳版本只上传“完整首帧图”作为首帧。若首帧中的皇帝身份仍不够稳，并且当前入口支持额外参考，再补传皇帝定妆图，写明“只保持皇帝身份和服装，不改变首帧构图”。不要把皇帝、太监、大殿和多张秀女图全部无说明上传。

### 视频Prompt

```text
从这张完整首帧开始，所有人物、服装、队列和大殿布局保持一致。0–1秒，皇帝肩背稳定、头部不动，只让视线从画面左侧平稳扫到中轴；太监双手交叠，两列秀女全部垂眼静止。1–2秒，皇帝视线继续扫到画面右侧并停半拍，随后才把右手掌心朝外抬到胸口高度，动作缓慢、克制，手掌到位后完全停住。2–3秒，皇帝保持手掌悬停，以低沉平静的语气说：“都退下吧。”句尾短而清楚。太监和秀女全程不提前反应、不退场。摄影机以对称大全景、轻低机位、标准偏广角感从殿门方向开始，做几乎不可察觉的极缓物理推近，始终保持皇帝位于中轴，终点仍为大全景并停稳0.5秒。宫灯暖光不变。
```

### 实际操作步骤

1. 在生图工具中生成首帧；有角色参考功能时绑定皇帝和太监身份，没有时先做好角色定妆图再参考生成。
2. 首帧检查通过后下载原图，不加字幕。
3. 打开当前Seedance入口，选择图生视频或首帧生成模式。
4. 上传完整首帧；设置9:16、3秒。若入口最低时长高于3秒，生成允许的最短时长，剪辑时截取前3秒。
5. 粘贴视频Prompt。若当前入口支持原生对白，可保留台词；不支持时删除声音句，生成后单独配音。
6. 首轮生成2–4个版本，只选身份、手势和队列最稳定的一条，不要因为某条运镜更炫而接受人物漂移。

### 验收标准

- 皇帝第0秒双手在身侧，第1秒后才抬右手。
- 皇帝只完成一次视线横扫和一次抬掌，没有转身或走路。
- 太监和秀女全程静止，没有提前退场。
- 皇帝脸、服装和手掌没有漂移或畸变。
- 摄影机只极缓推近，没有摇摆、变焦跳变或突然加速。
- 尾帧右掌停在胸口，能直接接下一镜。

### 首次失败只改什么

如果秀女乱动或皇帝手势变形，第一轮保守修复只改一个变量：把摄影机改为完全固定，保留人物动作不变。仍失败时，再把秀女数量减少并合成进首帧，不增加更多否定词。

## 声音与口型

- 台词短、机位固定、说话者单一时，可以尝试原生对白。
- 当前入口不支持原生声音，或口型反复失败时，先生成无对白表演，再后期配音；不要为了口型牺牲人物身份与手势。
- 画外音不要求角色动嘴，应在Prompt中明确“画外音”。
- 多人轮流对白优先拆镜或后期配音，不在移动镜头中要求多人精确口型。
